📘 Documentación General del Proyecto

❗ Planteamiento del Problema
Actualmente, muchas personas que llevan un estilo de vida saludable no cuentan con una herramienta unificada que les permita:

🏃 Gestionar su progreso físico

📝 Registrar entrenamientos

🍎 Controlar su alimentación

🔐 Contar con acceso seguro a la información

Esta falta de organización dificulta el seguimiento continuo, la disciplina y la toma de decisiones basadas en datos reales.

🎯 Objetivo General
Desarrollar un sistema de gestión de datos para usuarios físicamente activos que permita:

📈 Registrar, consultar y administrar información sobre progreso físico

🏋️‍♀️ Entrenamientos

🥗 Alimentación

🔐 Seguridad de acceso

Todo ello, a través de una base de datos estructurada y normalizada.

🎯 Objetivos Específicos

🧠 Diseñar un modelo entidad-relación (MER)
Crear un modelo lógico y normalizado que estructure los módulos de seguridad, nutrición y entrenamiento, incluyendo relaciones, claves y restricciones.

🗃️ Implementar una base de datos relacional en MySQL
Construir el esquema relacional con DDL en MySQL, aplicando 3FN para garantizar integridad y eficiencia.

⚙️ Desarrollar procedimientos almacenados, funciones y triggers
Automatizar operaciones CRUD y reglas de negocio para mantener la consistencia y eficiencia del sistema.

📊 Diseñar consultas SQL avanzadas
Implementar al menos 10 consultas con JOINs, filtros y agrupaciones para generar reportes valiosos.

🛡️ Implementar un modelo de seguridad robusto
Definir entidades como usuarios, roles y permisos para un control de acceso seguro y segmentado.

✅ Requisitos Funcionales
👤 Registro y autenticación de usuarios

🔐 Asignación de roles y permisos

🏋️‍♂️ Registro de entrenamientos y rutinas

🎯 Asociación de objetivos físicos

🥦 Gestión de dietas y alimentos

📅 Registro de progresos por fecha

📈 Consultas SQL con múltiples tablas

🛠️ Procedimientos CRUD automatizados

⚙️ Requisitos No Funcionales
📐 Base de datos normalizada hasta 3FN

🔗 Integridad referencial asegurada

🔒 Control de acceso por roles

🗂️ Organización clara de documentación y scripts

📌 Alcance del Proyecto
💾 Diseño e implementación de la base de datos relacional

🔐 Módulos de seguridad, nutrición y entrenamiento

👥 Registro de usuarios, rutinas, progresos, alimentos y objetivos
